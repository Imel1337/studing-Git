# Ритм — лабораторная работа №2

Офлайн-трекер ежедневных привычек на Java. Создавайте небольшие цели, отмечайте выполнение и наблюдайте за прогрессом. Приложение не требует регистрации и подключения к интернету.

## Запуск
1. Откройте папку проекта в Android Studio через File → Open.
2. Дождитесь Gradle Sync. Используются Gradle 9.6.0, Android Gradle Plugin 9.4.1, JDK 25, SDK Platform 37 и Build Tools 36.0.0.
3. Выберите подключённый телефон или эмулятор Android 8.0 (API 26) и новее.
4. Запустите конфигурацию app кнопкой ▶.

Из терминала: `./gradlew assembleDebug lintDebug`.
APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
Готовый установочный файл также приложен отдельно как `Ritm-debug.apk`.

## Использование
На первом запуске нажмите «Начать свой ритм». Добавятся три примера без выдуманных выполнений. На вкладке «Привычки» можно создать цель, найти её по названию или категории, выбрать идею из каталога. Название обязательно: от 2 до 80 символов.

На экране «Сегодня» отметьте выполнение. Повторное нажатие отменит отметку. Для каждой привычки доступна одна отметка за день. Серия — последовательные дни выполнения, заканчивающиеся сегодня или вчера.

В «Прогрессе» отображаются реальные отметки за последние семь дней и общая история. Архивирование сохраняет историю; привычку можно восстановить. В профиле можно изменить имя и мотивацию, в настройках — фразу на главном экране. Всё сохраняется в SharedPreferences и остаётся после перезапуска. Удаление приложения удаляет локальные данные.

## 13 экранов
Приветствие; Сегодня; Привычки с поиском; Создание/редактирование привычки; Детали привычки; Прогресс; История; Каталог идей; Профиль; Редактирование профиля; Настройки; О приложении; Архив.
Все экраны реализованы отдельными публичными Activity из Screens.java и зарегистрированы в AndroidManifest.xml. Навигация использует Intent и нижнее меню. Есть ошибки форм, пустые состояния, выбранная вкладка и состояния выполнения.

## Исходный код
- `Habit.java` — модель и JSON.
- `HabitRepository.java` — SharedPreferences, сохранение и статистика.
- `BaseActivity.java` — общие компоненты интерфейса и навигация.
- `Screens.java` — 13 экранов.
- `app/src/debug/.../SmokeTests.java` — инструментальные проверки сохранения, серий, архива и открытия экранов. Запуск после установки debug APK: `adb shell am instrument -w ru.lab.ritm/.SmokeTests`. Проверка сохраняет и восстанавливает исходные настройки приложения.

Архитектура: UI → Repository → SharedPreferences. Рекомендованный в задании MVVM/ViewModel в этой версии не используется.
